# 数据结构说明

## 1. 山海经.json

顶层结构：

```json
{
  "名称": "山海经",
  "原文": [...],
  "词条": [...]
}
```

### 原文（共 1907 条）

每条记录代表山海经中的一个句子。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 句子唯一标识，如 `"01-source-01-1"` |
| 段落id | string | 所属段落标识，如 `"01-source-01"` |
| 所属经文 | string | 经文名称，如 `"南山经"` |
| 句子 | string | 原文内容 |

### 词条（共 1765 条）

每条记录代表从原文中提取的一个实体（山、水、兽、草、木等）。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 词条唯一标识，如 `"01-01-1"` |
| 名字 | string | 实体名称，如 `"招摇山"` |
| 类别 | string | 实体类型：山、山系、水、兽、草、木 等 |
| 归属 | string | 父级词条id，表示层级归属关系（如山归属于山系） |
| 所属段落 | string | 关联的段落id → 指向原文的 `段落id` |
| 所属句子 | string | 关联的句子id → 指向原文的 `id` |
| 原文句子 | string | 转换时从原文表中关联填入的原文内容 |

### 关联关系

```
词条.所属句子 → 原文.id        （词条出自哪句原文）
词条.所属段落 → 原文.段落id     （词条出自哪个段落）
词条.归属     → 词条.id        （词条间的层级关系，如：草→山→山系）
```

## 2. 百草经.json

顶层结构：

```json
{
  "名称": "百草经",
  "条目": [...]
}
```

### 条目（共 1244 条）

每条记录代表一味药物。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 序号 |
| 名称 | string | 药物名称，如 `"丹沙"` |
| 别名(释名) | string | 别名，多个以 `/` 分隔，可为空 |
| 气味 | string | 药物性味，如 `"味甘平"` |
| 主治 | string | 功效与主治描述 |
| 附方 | string | 相关药方，可为空 |
| 生长 | string | 产地或生长环境，如 `"山谷"` |
| 考释 | string | 考证说明，可为空 |
