# 古籍数据爬取

从 [劝学网](https://www.quanxue.cn/) 爬取中国古籍全文，保存为 Markdown 文件。

## 目录结构

```
.
├── README.md
├── scripts/
│   ├── scrape.py              # 山海经爬取脚本
│   ├── scrape_gangmu.py       # 本草纲目爬取脚本
│   └── scrape_bencao.py       # 神农本草经爬取脚本
├── 山海经/                     # 19 个章节文件
│   ├── 00_导读.md
│   ├── 01_南山经.md
│   ├── ...
│   └── 18_海内经.md
├── 本草纲目/                   # 185 个分页文件
│   ├── 001_水部(01).md
│   ├── ...
│   └── 185_人部(02).md
└── 神农本草经/                  # 15 个章节文件
    ├── 01_总论.md
    ├── 02_玉石部(上品).md
    ├── ...
    └── 15_米谷部.md
```

## 使用方法

```bash
# 爬取山海经（19 章）
python3 scripts/scrape.py

# 爬取本草纲目（185 页）
python3 scripts/scrape_gangmu.py

# 本草纲目支持断点续传，从指定页码开始
python3 scripts/scrape_gangmu.py 159

# 爬取神农本草经（15 章）
python3 scripts/scrape_bencao.py
```

## 山海经

- **来源**：https://www.quanxue.cn/ct_baijia/shanhaiindex.html
- **内容**：1 篇导读 + 18 卷正文，共 19 个文件
- **格式**：每段包含 **原文**、**译文**、**注释**

## 本草纲目

- **来源**：https://www.quanxue.cn/ct_zhongyi/gangmuindex.html
- **内容**：16 部分类，共 185 页
- **格式**：每味药包含 **释名**、**气味**、**主治**、**附方**

| 部 | 页码 | 部 | 页码 |

## 神农本草经

- **来源**：https://www.quanxue.cn/ct_zhongyi/bencaoindex.html
- **内容**：1 篇总论 + 14 章分类，共 15 个文件，收录 365 味药
- **格式**：每味药包含 **名称**、**气味**、**主治**、**别名**、**生长**
- **分类**：玉石部、草部、木部、虫兽部、果菜部、米谷部（各分上/中/下品）
